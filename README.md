Premium MasterClass EDU - Full Web + Mobile Prototype
=====================================================

This project is a prototype scaffold for a premium educational app (Web + Mobile).
It includes:
- Splash -> Home navigation
- Premium-style subject tiles
- GPA calculator stub
- Theme (light/dark)
- Placeholders for assets and 3D models

How to run locally:
1. Install Flutter SDK
2. flutter pub get
3. flutter run -d chrome   # for web
4. flutter run -d emulator # for android

Notes:
- This is a frontend prototype. Advanced features (AI, 3D rendering, scraping) need backend/API keys.
